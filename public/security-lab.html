Security lab · Attack 01

Brute force, in the browser.

Wordlist attack against the sign-in behind login.html — run entirely on this page, no terminal needed.

Authorized testing on your own project only. Runs are hard-capped at 25 attempts, at least 500 ms apart, and stop on success or Firebase lockout. This page is not linked from the site navigation.

How to run the attack

  1. Create a throwaway lab account (or type an account you own).
  2. Press Start attack and watch the wordlist fire.
  3. Read the verdict — cracked, locked out, or not cracked.
  4. Delete the lab account when you're done.

Attack log

#CandidateServer responseTime

No attempts yet — press Start attack.

What this proves

Every attempt goes to the exact endpoint login.html uses (Firebase Identity Toolkit accounts:signInWithPassword). A password inside the wordlist falls in a handful of tries — which is why the mitigation is password strength plus Firebase's lockout, not the login form itself. Full write-up: docs/attacks.md. Terminal version: scripts/security/brute-force.mjs.
